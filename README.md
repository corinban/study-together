# Study Together

一个简洁的线上自习网站，支持离线使用，也可以通过 Node.js 服务开启实时联机功能。

## 本机运行

需要 Node.js 20 或更新版本。在项目文件夹打开终端并运行：

```bash
npm install
npm start
```

然后打开 `http://localhost:3000`。也可以直接打开 `index.html` 使用离线功能；直接打开网页文件时，账号、实时房间和云端 AI 不可用。

## 已保留的功能

- 离线/联机模式切换；离线专注记录在登录后可补记。
- 可选账号、唯一 ID、昵称、在线人数、房间创建与邀请。
- 自习房间独立页面；进入房间时填写目标，查看 AI 或本地生成的学习时间表。
- 计时只在房间内进行；可调专注与休息时长，离开房间会暂停。
- 任务、专注统计、学习备忘录、白噪音、社区、答疑和双排行榜。
- 自习结束正餐转盘，可刷新菜品并点击转动。
- 连续学习休息提醒。

个人计时、任务和备忘录保存在浏览器；账号、房间和社区数据保存在服务端 `data.json`。公开部署时请配置持久化存储，以免服务重启后数据丢失。

## AI 接口

AI 调用保留在 `server.js` 服务端。将 `.env.example` 复制为 `.env`，填入 `OPENAI_API_KEY`；可用 `OPENAI_MODEL` 指定模型。密钥只放在服务端环境变量中，不能放入网页文件。没有密钥时，学习规划会自动使用本地时间表。

托管平台上请在服务的环境变量设置中填写 `OPENAI_API_KEY`，无需更改网页代码。

## 部署

可部署为 Node.js Web Service，启动命令为 `npm start`，健康检查路径为 `/health`。也提供 `Dockerfile`，可用于支持 Docker 的主机。挂载持久化目录后，把 `DATA_FILE` 指向该目录中的数据文件。

`render.yaml` 提供 Render Blueprint 配置。部署后，联机功能通过服务地址访问；静态托管只支持离线功能。
